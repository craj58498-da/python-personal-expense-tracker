# Personal Expense Tracker

A beginner-level Python project to manage
daily expenses.

## Features
- Add Expenses
- View Expenses
- Calculate Total Expenses
- Search by Category
- Delete Expenses
- Save Data in JSON File

## Technologies Used
- Python
- JSON
- File Handling

## Concepts Used
- Variables
- Loops
- Conditional Statements
- Lists
- Dictionaries
- Functions
- Exception Handling

## How to Run

1. Install Python.
2. Download this repository.
3. Open terminal.
4. Run:

python main.py
